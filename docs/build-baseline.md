# Build Baseline

Retain:
- GitHub repository: staffroom-review/staffroom-website
- Vercel project/deployment: staffroom-website
- package.json and its dependency set

Rebuild:
- app/
- components/
- data/

No previous homepage markup or CSS is authoritative.

Rules:
- semantic HTML
- one coherent global design system
- responsive grid/flex
- no magic offsets
- no duplicated design systems
- content separated from presentation
- existing Staffroom content preserved
- temporary image placeholders allowed until the imagery pass

The page must be verified visually at the reference dimensions before final imagery work.
