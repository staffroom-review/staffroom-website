# Screenshot Analysis

## Reference geometry

Supplied screenshots are 1440 × 900 captures. The visible webpage content field is approximately 1320px wide with about 60px left/right margins. Use this as the primary desktop calibration.

The reference is a publication page, not a uniform card grid.

Shared characteristics:
- warm paper surface
- dark brown-black serif headlines
- softer serif supporting text
- bright red accent for labels and long rules
- tight headline leading
- compact uppercase micro-labels
- thin story separators
- large rectangular images
- variable image scale by editorial importance
- intentional whitespace
- strong change in density between feature and collection sections
- deliberate asymmetric compositions
