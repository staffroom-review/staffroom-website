# Staffroom Review — Screenshot Analysis

## Capture basis

All supplied screenshot files are 1440 × 900 pixels.

The screenshots include browser chrome and the operating-system dock. For layout comparison, the webpage begins at approximately y=112 and the visible webpage ends near y=834. A persistent bottom access banner occupies approximately the final 70px of the webpage view.

The principal horizontal content field in the screenshots is approximately:

- left margin: 60px
- right margin: 60px
- usable editorial width: approximately 1320px

These values are working measurements from the screenshots and are visual calibration points.

## Shared visual system observed across Sections 1–7

### Surface
The page uses a warm, slightly pink/ivory paper tone rather than bright white as the default page field. Some feature story bodies use a lighter paper/white surface.

### Ink
Headlines are a very dark brown-black. Supporting text is materially lighter and softer.

### Accent
A bright vermilion/red is reserved for:
- author/section micro-labels
- section headings
- section rules
- selected controls

It is a high-contrast editorial accent, not a page-wide background colour.

### Typography
The display hierarchy is serif-first.

Observed relationship:
- large feature headline
- medium feature headline
- compact editorial headline
- small serif/sans-serif supporting copy
- very small uppercase red labels

Headlines are relatively tight in line-height and often use narrow text blocks to control wrapping.

### Grid
The page is not a single repeating card grid.

The dominant systems are:
- three-column asymmetric feature compositions
- large feature + narrow support column
- three-column recommendation/collection layouts
- five-column dense newsletter/collection layout

The central feature in three-column compositions is visually dominant and approximately twice the width of a side column.

### Spacing
Internal story spacing is tight. Inter-section spacing is generous but controlled.

The visual rhythm is:
compact story package → divider → compact story package → large feature → whitespace → new composition

### Rules
Thin grey rules separate editorial units. Long accent rules identify section starts.

### Image treatment
Images are rectangular and mostly edge-to-edge within their column. Crops are controlled by the editorial role:
- large feature image: dominant horizontal rectangle
- secondary image: medium landscape rectangle
- collection lead image: compact landscape rectangle

There are no globally repeated rounded cards.

### Surfaces and shadows
Most stories are flat. Any paper-lift/shadow treatment should be sparse and only used where the reference composition benefits from a raised surface.

## Section 1 — Opening composition

Structure:
- left text-led story column
- large central feature column
- right supporting/utility column

The central image is the largest visual element and starts high in the composition. The left and right text columns sit lower than the top of the central image, creating a deliberate stagger.

The central feature combines:
large image → small red label → very large serif headline → supporting text

The left side contains a substantial text-led story followed by an image-led promotional/editorial tile.

The right side contains a pale support/commentary box with:
- centered small heading/icon area
- large serif headline
- multi-line supporting copy
- outlined action button

This right module is a publication-utility counterpart in Staffroom rather than a literal comments clone.

### Proportional target
At the 1320px content width, use an approximate:
3 : 6 : 3 column relationship
with small gutters, but calibrate the central feature and side text widths visually at the reference viewport.

## Section 2 — Feature plus support

Structure:
- large left feature occupying the dominant width
- narrow right editorial column
- right column contains a text-led story followed by an image-led story

The large feature uses:
large horizontal image → centered/contained headline and dek block

The feature headline is large but materially smaller than a masthead or display title. The image establishes most of the feature's physical height.

The right column uses smaller type and tighter story packages.

### Proportional target
Approximate visual relationship:
dominant feature : support = 2 : 1
with the support column materially narrower.

## Section 6 — Newsletter/collection grid

The five columns should have equal visual widths and consistent gutters. This is one of the clearest symmetric compositions in the reference.

### Proportional target

5 equal columns
with consistent gutters across approximately 1320px.

The bottom of the screenshot demonstrates that the section is vertically substantial and visually anchored by the central feature.

## Responsive principles

Desktop screenshots establish horizontal geometry.

Mobile must preserve:
- reading order
- dominant story first
- image prominence
- headline-to-dek relationship
- section rule
- density hierarchy

Mobile is not a scaled desktop grid.

Tablet is an intermediate composition derived from the same underlying relationships.

## Verification

Every section must be checked at the reference viewport before moving to the next section.

Comparison should focus on:
- left/right edges
- column starts
- image rectangles
- headline block widths
- vertical starts
- section heading/rule alignment
- whitespace before and after major features
- density of compact lists
