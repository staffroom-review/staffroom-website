# Staffroom Review — Homepage Reference Mapping Guide

## Purpose

This is a **reference-comparison guide**, not a mandatory one-to-one replication contract.

The primary visual and structural evidence is the screenshot set supplied by the user and documented in `docs/reference-capture-and-analysis.md`.

The goal is for Staffroom Review to be as close as practical to the reference in:
- overall page depth
- approximate section count
- story/card density
- hierarchy
- module variety
- whitespace rhythm
- image prominence
- page cadence

Exact card-for-card or module-for-module correspondence is not required.

## 1. Reference evidence

## 2. Comparison rule

For each major reference area, identify the closest Staffroom treatment.

Preserve where practical:
- relative sequence
- visual prominence
- approximate footprint
- story density
- card-size variation
- image importance
- section rhythm

Staffroom may:
- combine adjacent modules
- split a dense group
- add Staffroom-specific editorial modules
- vary story counts slightly
- adapt formats for readability or editorial purpose

Do not use this flexibility to produce a materially shorter or flatter homepage.

## 5. Acceptance test

The homepage should pass when comparison against the supplied screenshots shows:
- broadly comparable page depth
- broadly comparable section scale
- broadly comparable story density
- similarly varied layouts
- similar hierarchy and pacing
- similar image prominence
- coherent desktop/mobile transformation

It fails if it becomes:
- materially shorter
- materially sparser
- a repeated generic grid
- dominated by decorative text instead of stories
- missing major reference patterns without a deliberate Staffroom reason

## 6. Responsive rule

Desktop and mobile screenshots are the primary reference states.

Tablet should normally be derived from the same responsive system and then refined at intermediate widths. A separate tablet implementation is only warranted when the reference demonstrates genuinely different behaviour.

## 7. Source note

The reference should be judged from the supplied screenshot set and not reconstructed from memory or partial web evidence.
